## Cómo leer la documentación de AWS

- **Guía del usuario:** conceptos y tareas paso a paso. Empieza siempre por aquí.
- **Referencia de la API o de la CLI:** cada operación con sus parámetros; útil para automatizar.
- **Preguntas frecuentes (FAQ) del servicio:** respuestas cortas, muy útiles para el examen.
- **Página de precios del servicio:** qué se cobra y cómo.
