# Módulos del curso

El curso *AWS Cloud Practitioner Essentials* tiene 13 módulos. Cada módulo publicado incluye lecciones con teoría, ejemplos y casos, diagramas con los iconos oficiales de AWS, notas rápidas, un laboratorio con scripts de verificación, una evaluación de opción múltiple con respuestas explicadas y las trampas típicas del examen.
