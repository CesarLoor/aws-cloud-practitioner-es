# Sílabo del curso

!!! abstract "Sílabo de estudio"
    Guía del curso AWS Cloud Practitioner Essentials organizada como una asignatura universitaria, para estudiar de forma individual o en grupo y preparar la certificación AWS Certified Cloud Practitioner (CLF-C02).

## 1. Datos informativos

| Campo | Detalle |
| --- | --- |
| Curso base | AWS Cloud Practitioner Essentials (AWS Skill Builder, versión 2025 de 13 módulos) |
| Certificación objetivo | AWS Certified Cloud Practitioner (CLF-C02) |
| Nivel | Fundamental; no requiere experiencia previa en la nube |
| Modalidad | Autoestudio en línea con laboratorios prácticos en una cuenta de AWS |
| Duración sugerida | 8 semanas, de 4 a 6 horas por semana |
| Idioma | Español, con los nombres oficiales de los servicios en inglés |

## 2. Descripción

El curso desarrolla una comprensión general de la nube de AWS: conceptos de computación en la nube, infraestructura global, servicios principales (cómputo, redes, almacenamiento, bases de datos, IA/ML y análisis), seguridad y cumplimiento, supervisión y gobernanza, precios y soporte, migración y arquitectura bien diseñada. Combina explicación teórica, diagramas con los iconos oficiales de AWS, casos reales y laboratorios guiados.

## 3. Objetivos

**Objetivo general:** comprender cómo funciona la nube de AWS y cómo sus servicios resuelven necesidades de negocio, con la base necesaria para aprobar el examen CLF-C02.

**Objetivos específicos:**

1. Explicar los conceptos y beneficios de la computación en la nube y la infraestructura global de AWS.
2. Identificar los servicios principales de AWS y elegir el adecuado para cada caso.
3. Aplicar el modelo de responsabilidad compartida y las buenas prácticas de seguridad.
4. Usar las herramientas de supervisión, gobernanza, precios y soporte.
5. Describir estrategias de migración y los pilares de una arquitectura bien diseñada.
6. Realizar laboratorios básicos en AWS de forma segura y sin costos innecesarios.

## 6. Metodología

1. **Lección en Skill Builder** y luego su página en esta guía: explicación, diagramas y casos.
2. **Notas rápidas** del módulo para fijar los conceptos clave.
3. **Laboratorio guiado** con configuración, pruebas de verificación (con script) y limpieza.
4. **Evaluación del módulo** de opción múltiple con explicaciones de cada respuesta.
5. **[Repaso rápido](repaso/repaso-rapido.md)** y **[simulacro de examen](repaso/simulacro.md)** al cerrar cada bloque de módulos.

## 7. Evaluación sugerida

Para grupos de estudio o para medir tu propio avance:

| Componente | Peso | Criterio de aprobación |
| --- | --- | --- |

| Laboratorios | 30 % | Pruebas de verificación superadas y limpieza confirmada |
| Simulacro integrador | 40 % | 80 % o más antes de programar el examen real |

## 9. Requisitos técnicos

- Navegador actualizado y una cuenta de AWS configurada según el [Entorno de práctica](entorno/index.md).
- Correo electrónico, teléfono y tarjeta para registrar la cuenta.
- Opcional: AWS CLI en tu computadora (todos los laboratorios funcionan con CloudShell).
