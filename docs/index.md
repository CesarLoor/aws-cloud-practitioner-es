# AWS Cloud Practitioner en español

Guía de estudio abierta y gratuita para preparar la certificación **AWS Certified Cloud Practitioner (CLF-C02)**. Sigue los 13 módulos del curso *AWS Cloud Practitioner Essentials* de AWS Skill Builder y los organiza como una asignatura completa: lecciones con explicación, diagramas con los iconos oficiales de AWS, casos de uso, notas rápidas, laboratorios que puedes ejecutar en tu propia cuenta y evaluaciones con respuestas explicadas.

!!! warning "Proyecto comunitario"
    Este material no es oficial ni está afiliado a Amazon Web Services. Úsalo junto con el curso gratuito de [AWS Skill Builder](https://skillbuilder.aws/) y la [documentación oficial](https://docs.aws.amazon.com/). Las condiciones de la capa gratuita y los precios cambian: confírmalos siempre en las páginas de AWS.

## Empieza aquí

1. **Prepara tu cuenta** con el [Entorno de práctica](entorno/index.md): crear la cuenta, recorrer la consola y dejarla segura y con alertas de costo.
2. **Estudia módulo por módulo** desde la página de [Módulos](modulos.md).
3. **Haz el laboratorio** de cada módulo y ejecuta sus scripts de verificación.
4. **Responde la evaluación** sin mirar las respuestas y repasa las trampas típicas del examen.

## Cómo estudiar cada módulo

1. Haz la lección en Skill Builder y luego lee su página aquí: explicación, diagramas y casos.
2. Repasa las **notas rápidas** del módulo.
3. Haz el **laboratorio** y su limpieza.
4. Responde la **evaluación** del módulo.
5. Lee las **trampas típicas del examen** antes de pasar al siguiente.

## El examen CLF-C02 en breve

| Dato | Valor |
| --- | --- |
| Preguntas | 65 (50 puntúan y 15 no puntúan) |
| Duración | 90 minutos |
| Formato | Opción múltiple y respuesta múltiple |
| Puntaje para aprobar | 700 / 1000 |
| Costo | 100 USD |
| Vigencia | 3 años |

| Dominio del examen | Peso | Módulos |
| --- | --- | --- |
| 1. Conceptos de la nube | 24 % | 1, 4, 12, 13 |
| 2. Seguridad y cumplimiento | 30 % | 1, 5, 9, 10 |
| 3. Tecnología y servicios de la nube | 34 % | 2 a 8, 10 |
| 4. Facturación, precios y soporte | 12 % | 2, 11 |

Página oficial: [AWS Certified Cloud Practitioner](https://aws.amazon.com/certification/certified-cloud-practitioner/).
